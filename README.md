# Image Gallery Grid

A simple and responsive image gallery built with **HTML and CSS**.
The project includes a grid-based layout, image zoom effects, and hover captions.

## Live Demo

[View Live Demo](https://404kin.github.io/image-gallery-grid/)

## Features

* Responsive image gallery
* CSS Grid layout
* Image zoom effect on hover
* Image captions with hover animation
* Responsive design for desktop, tablet, and mobile devices
* Clean and simple UI

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* CSS Media Queries

## Project Structure

```text
image-gallery-grid/

    ├── pic2.jpg
    ├── pic4.jpg
    ├── pic5.jpg
    ├── pic6.jpg
    ├── pic8.jpg
    └── pic9.jpg
```

## Responsive Design

The gallery adjusts its layout based on screen size:

* **Desktop:** 3 columns
* **Tablet:** 2 columns
* **Mobile:** 1 column
